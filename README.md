## 📖 Sobre o Projeto

Este projeto consiste no desenvolvimento de um site responsivo criado como atividade acadêmica da disciplina de Tecnologias para a Internet, com o objetivo de aplicar conceitos de desenvolvimento web utilizando HTML, CSS e JavaScript.

O sistema foi desenvolvido com foco em organização, usabilidade e boas práticas de estruturação de páginas web.

---

## 🎯 Objetivos

- Aplicar conceitos de desenvolvimento front-end;
- Praticar a estruturação semântica com HTML;
- Utilizar CSS para estilização e responsividade;
- Implementar interatividade com JavaScript;
- Desenvolver uma interface amigável para o usuário.

---

## 🛠️ Tecnologias Utilizadas

- HTML
- CSS
- JavaScript
- Git
- GitHub
